# Stockholm Welcome Guide

**Your personal assistant after landing at Arlanda Airport (ARN)**

---

### About the Project
This web application helps international travelers arriving at Stockholm Arlanda Airport by showing real-time flight arrivals, weather information, and practical guidance for getting to the city center and visiting tourist attractions.

### Features
- Displays real-time arrivals at Arlanda Airport
- Shows current weather in Stockholm
- Provides best transportation options from the airport (Arlanda Express, Flygbussarna, SL)
- Clean and modern dark theme design
- Fully responsive (works well on mobile)

### Technologies Used
- **Backend**: Python + Flask
- **Frontend**: HTML, CSS
- **Template Engine**: Jinja2
